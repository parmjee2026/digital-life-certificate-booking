# Digital Life Certificate Appointment Booking

Updated static website for Digital Life Certificate (Jeevan Pramaan) appointment assistance.

## WhatsForm integration
- Embedded appointment form: https://whatsform.com/DF9tRe
- Floating WhatsApp launcher uses the same WhatsForm ID: `DF9tRe`
- The embedded form is responsive and has a mobile-specific height.
- A direct form link is provided as a fallback if embedding is blocked.

## Existing details retained
- WhatsApp assistance number: `+91 88516 26759`
- Required documents/details checklist
- Privacy notice
- Independent-service disclaimer
- No database or backend required
- GitHub Pages compatible

## Publish with GitHub Pages
1. Extract this ZIP.
2. Upload/replace `index.html` in the repository root (or upload the extracted files).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. Wait for GitHub Pages to publish the site.

## Important
This is an independent appointment-assistance website, not an official Government of India or Jeevan Pramaan portal. The WhatsForm widget helps visitors submit an appointment enquiry; it does not itself confirm an appointment. Confirm each booking manually.

Do not request or collect Aadhaar numbers, PPO numbers, bank details, OTPs, or other sensitive credentials through this public form unless a secure and necessary process has been independently verified.
